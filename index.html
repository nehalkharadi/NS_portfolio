CRITICAL BUG-HR-101 Status: OPEN

HRMS: Annual leave balance calculates negative value when submitting overlapping dates

Project: HRMS Application
Environment: Chrome v122 / Windows 11 / Staging v2.4
Reported By: Manual QA Specialist
Component: Leave Tracker Module
Description & Impact

When an employee submits a leave request with dates overlapping an existing approved holiday weekend, the leave counter fails to validate business day deductions and produces a negative balance (e.g., -3 days), bypassing maximum allowed quota.

Steps to Reproduce (100% Reproducible)
  1. Log in to the HRMS portal as standard employee (emp_user_04).
  2. Navigate to Leave Tracker → Request Leave.
  3. Select Leave Type: Annual Paid Leave.
  4. Set Start Date: 2026-11-20 (Friday) and End Date: 2026-11-23 (Monday).
  5. Click the "Submit Request" button.
  6. Observe the "Remaining Leave Days" summary widget on the dashboard.
✓ Expected Result

System deducts only 2 business days (Friday + Monday), excluding Saturday & Sunday, displaying 8 remaining days from initial 10-day balance.

✗ Actual Result

System deducts 4 consecutive calendar days and subtracts an extra buffer penalty, causing remaining balance to display -3 days without throwing validation error.
